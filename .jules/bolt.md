## 2024-10-02 - React Hooks and Array Manipulations\n**Learning:** Heavy array manipulations like `.map`, `.filter`, and `.reduce` inside React components recalculate on every re-render (e.g., when clicking tabs, or copying text) if not memoized, which can be an unexpected bottleneck.\n**Action:** Use `useMemo` for expensive array operations derived from props, especially in dashboard-heavy components like `repo-analyzer` and `pr-review-panel`.
