## 2023-10-15 - [Added HNSW Index for pgvector]
**Learning:** Adding an HNSW index to a `pgvector` column using Drizzle ORM requires specific syntax like `index("code_chunk_embedding_idx").using("hnsw", table.embedding.op("vector_cosine_ops"))` inside the table's configuration callback. Without this index, vector similarity searches using `<=>` (cosine distance) fallback to a full table scan, degrading performance to O(N). The HNSW index transforms this into an O(log N) approximate nearest-neighbor search.
**Action:** When working with `pgvector` in Drizzle ORM, always verify that an appropriate vector index (like HNSW or ivfflat) is present on the embedding column to ensure scalable similarity search performance. Ensure inline comments are added immediately alongside the index creation detailing the optimization logic.
